    How to Use & Prerequisites

    1. Snap a Picture

    Find discarded items like glass bottles, cardboard, or plastic. Ensure the subject is clearly visible in the photo.

    2. AI Processing

    Our backend Vision Transformer classifies the material, while the generative AI synthesizes a high-res concept image.

    3. Build It

    Follow the dynamically generated step-by-step DIY instructions and gather the required tools to build your project.

    Hackathon Features

    Computer Vision

    Utilizes advanced image classification to identify materials with high accuracy, correcting mobile EXIF data automatically.

    Generative Synthesis

    Transforms the detected text prompt into a photorealistic, studio-quality image of the final upcycled product.

    Async FastAPI Backend

    Built for speed and scale. Handles multi-part file uploads and API bridging asynchronously without blocking the main thread.
